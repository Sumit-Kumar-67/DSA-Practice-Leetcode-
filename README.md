# Problem-Solving Patterns

Apart from data structures, I will also categorize problems according to commonly used problem-solving patterns.

| Pattern              | Description                                         |
| -------------------- | --------------------------------------------------- |
| Two Pointers         | Solve problems using two moving indices             |
| Sliding Window       | Process contiguous subarrays/substrings efficiently |
| Binary Search        | Reduce search space by half                         |
| Prefix Sum           | Efficient range/subarray calculations               |
| Fast & Slow Pointers | Detect cycles or find middle elements               |
| Hashing              | Fast lookup and frequency counting                  |
| Monotonic Stack      | Solve next greater/smaller problems                 |
| BFS                  | Level-by-level graph/tree traversal                 |
| DFS                  | Depth-based graph/tree traversal                    |
| Backtracking         | Explore possible choices and undo decisions         |
| Greedy               | Make the best local choice                          |
| Dynamic Programming  | Store results of overlapping subproblems            |
| Divide & Conquer     | Break a problem into smaller subproblems            |
| Bit Manipulation     | Use binary/bitwise operations                       |
| Topological Sort     | Process dependencies in a directed graph            |
| Union Find           | Solve connectivity problems                         |
